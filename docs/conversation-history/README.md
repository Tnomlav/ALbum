# Album 对话历史归档

本目录保存与 Album 项目工作目录关联的 Codex 任务中的可见对话记录，按任务拆分。

## 导出边界

- 包含用户消息，以及 Codex 可见的 commentary 和 final 回复。
- 不包含模型内部逐步思考过程（隐藏 Chain-of-Thought）。
- 不包含原始工具调用、命令输出、账号信息、Cookie、令牌、密码、密钥和其他敏感凭据。
- 其他项目工作目录的任务未纳入本归档。
- `<ALBUM_ROOT>` 是本机项目绝对路径的脱敏占位符。
