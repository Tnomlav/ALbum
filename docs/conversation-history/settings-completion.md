## 82. Codex (final_answer)

原因已经确定：应用回收站里残留了失效的媒体 URI：

`content://media/external/images/media/252`

系统查询结果是 `No result found`，日志明确报错：

```text
IllegalArgumentException: Invalid Uri: content://media/external/images/media/252
```

[AlbumApp.kt](<LOCAL_PATH>/AndroidStudioProjects/Album/app/src/main/java/com/example/album/ui/AlbumApp.kt:623) 把所有回收站 URI 一次性交给 `MediaStore.createDeleteRequest()`，其中一个失效就会导致整个请求失败。而 [CleanupRepository.kt](<LOCAL_PATH>/AndroidStudioProjects/Album/app/src/main/java/com/example/album/data/CleanupRepository.kt:204) 对系统回收站记录不检查原 URI 是否仍然存在，所以失效记录一直保留。

不是 `MANAGE_MEDIA` 权限导致的。这个权限当前确实未授予，但正常情况下仍应弹出系统确认框。真正问题是失效 URI 污染了批量请求；有效的 `446`、`440` 等文件仍在系统回收站，却被 `252` 一起拖失败了。修复时需要先过滤并清除失效记录，再对剩余 URI 发起彻底删除请求。
