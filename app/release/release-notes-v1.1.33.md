# Album v1.1.33

## 上上次封包至上次封包

- 完成 Pixiv 归档主页和归档注意事项引导，支持画师、Tag、来源目录和归档目录检索。
- 优化 Tag 本地读取、Pixiv 同一 Tag 对象的多语言关联、批量扫描和已移动文件清理。
- 统一移动逻辑，修复移动被当作复制、重复文件和批量移动后原位置残留的问题。
- 增加壁纸队列和壁纸管理页，支持静态/动态分类、加入顺序、排序、搜索、多选清除和独立清空。
- 增加图片与视频壁纸服务、动态壁纸低功耗模式、后台播放、声音模式、音量叠加和静态壁纸轮播。
- 完善播放器菜单、信息、镜像翻转、后台暂停、音频焦点、播放顺序和屏幕方向处理。

## 上次封包至本次封包

- 编辑器替换原图时保留原文件名、Tag 和所在文件夹；保存副本时继承母文件 Tag 并保存到母文件目录。
- 播放器方向模式持久化，下次打开继续使用上次的自适应、横屏或竖屏设置。
- 图片查看器菜单恢复白色不透明，仅视频播放器菜单使用黑色半透明样式；清除操作显示为红色。
- 壁纸裁剪页增加左右 90 度旋转，以及 `-45` 至 `45` 度的连续角度调整，预览与导出保持一致。
- 壁纸设置的非开关选项改为右侧显示当前值，二级选项改为居中滚动选择器；修复自定义轮播时间弹窗。
- 壁纸管理顶栏拉开切换与应用/清除操作间距，并优化清除状态视觉反馈。
- Release 构建产物更新为已签名的 `v1.1.33`。
